# Denta PWA

نسخه اولیه رابط کاربری فارسی دنتا.

## فایل‌ها
- `index.html`: صفحه اصلی
- `style.css`: طراحی واکنش‌گرا، راست‌چین و حالت تاریک
- `app.js`: تعاملات اولیه و ثبت Service Worker
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: کش اولیه برای دسترسی آفلاین

## نکته مهم
این نسخه هنوز به Supabase متصل نیست. قبل از استفاده واقعی، احراز هویت و دسترسی‌ها باید با Supabase و RLS پیکربندی و آزمایش شوند. کلید `service_role` هرگز نباید در فایل‌های مرورگر قرار بگیرد.
